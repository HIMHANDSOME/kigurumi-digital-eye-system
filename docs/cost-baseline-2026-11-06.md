## 1. 预算必须拆开

总项目预算至少分别记录：

1. 可复用开发板与仪器；
2. **一次性 NRE**：设计、软件/固件、人力、结构治具、RF review、测试与试错；
3. 变动 BOM（双屏、控制器、UWB、驱动、电源、存储、线束、结构件）；
4. 组装/校准/功能测试；
5. 良率/返修、售后备件；
6. 税运、进口、渠道、包装；
7. 法规检测与认证；
8. Camera Beacon（不能隐藏在头壳 BOM 内）；
9. 完整头壳本身、假发、眼眶饰面（若未来销售包包含这些部件则另计）。

## 4. 人民币测算示例（不是实时汇率）

模型参数：**FX_USD_CNY = 7.20**（仅示例；实际使用付款时点结算汇率）。则：

- 100 台单台 BOM + 装测：约 ¥2,398–4,162；
- 1000 台单台 BOM + 装测：约 ¥1,771–3,053；
- 100 台场景不含其它费用的小计：约 ¥239,760–416,160；
- 1000 台场景不含其它费用的小计：约 ¥1,771,200–3,052,800；
- Beacon：原研究另预算 $25–60/台@100，$18–45/台@1000，需另行加总。

**计算公式：**

~~~text
Unit landed cost =
  BOM
+ Assembly and Test
+ Scrap / Rework allocation
+ Freight / Duties / Taxes
+ Beacon (if bundled)
+ Packaging
+ Warranty reserve

Total project spend =
  Unit landed cost * units
+ NRE (design, firmware, app, fixtures, RF, certification)
+ Support / Distribution expenses
~~~

## 6. 关键敏感性

- 每块 EPD 单价涨 $20 → 两块使每台 BOM 增 $40，未计税运/损耗。
- 屏损耗/返修率从 1% 上升至 5% 可能明显吞噬小批利润，需要实际良率测试。
- UWB 模组贵几美元通常不如屏供货、认证、手工校准 15–20min/台重要。
- 售价不应仅取 BOM×系数；研发、渠道、税、售后与市场需求尚未验证。
- 若目标售价很低或无力承担专用柔性屏 MOQ，优先评审非柔性备选路线，而非在物料清单上假装已降价。

## 7. 时间/人力

原研究计划总量 15.5 / 27.7 / 45.0 人月（低/典型/高）；成熟 3–5 人跨学科团队典型 11–15 个月，1–2 人串行典型 18–26 个月。中国企业研发全负担人月预算假设约 ¥35,000–60,000，典型 27.7 人月约 ¥97–166 万。它是工程成本模型，**个人开发现金支出不等于雇佣全团队预算**。

## 8. 更新规则

任何成本数值要升级为“verified quote”，必须提交：供应商、报价文件或截图、原厂 SKU、数量级、含税运情况、币种、日期、有效期、付款交期、良率/返修条款及备选来源。不得把 B2B 平台抓到的玻璃 EPD 售价替代“最终柔性屏”报价。
