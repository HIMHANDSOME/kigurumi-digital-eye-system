## 0. 执行摘要

**总判断：有条件继续（Conditional Go）；不得直接进入最终 PCB 或小批量采购。**

RW612、SR250、BLE/Wi-Fi、Head Fit、手机预览、手动发送、microSD 本地素材等技术有可行的工程路线。决定首代实体产品能否按原始约束交付的首要不确定性，是 **约 7 英寸、真正柔性基板、彩色、可采购、可合法/可持续驱动的电子纸**。第二大风险是 SR250 在实际佩戴的头壳中能否稳定输出摄影机相对方向。

当前常见 7.3 英寸 Spectra 6 产品可用作全彩 EPD 电气代理样机，但公开官方型号采用 **玻璃基板**，不能用其验证“柔性头壳眼片”需求。没有完整料号、基板说明、驱动/波形使用权限、最小弯曲半径、供货和价格书面证据，不得宣称满足最终屏规格。[R1][R2]

V1 的实际可验收功能应收敛为 **静态 E-Ink 眼片 + 离散 Sequence + 手机 2D Preview/Send + 每头壳 Head Fit + 本地素材管理 + UWB 追踪预览**；连续 30/60 fps 动画、压缩视频解码、实时实体跟眼明确留给 OLED/LCD Display Plane。3D 预览属于后续里程碑，不应阻塞首个可用的双眼样机。

**经济性：适用于高客单价、定制/小批量场景；研发和认证成本不能由 BOM 直接替代。** 研究给出的量产 BOM+装配/测试区间在 100 台时约 **$333–578/台**，1000 台时约 **$246–424/台**。这些是推算区间，不是柔性彩色 EPD 实际供应商的有效报价，且原模型没有包含所有商业费用。

## 3. 首要风险：真正柔性彩色 EPD

### 3.1 为什么“市场有 7.3″ 彩色 E-Ink”不等于需求已解决

以 E Ink 公开 7.3″ Spectra 6 为例：800×480、127 ppi、约 160×96 mm 有效区域，能用于成熟彩色 EPD 控制验证；但相应公开料号为玻璃背板。[R1][R2] “彩色”“可反射显示”“7.3 英寸”“电子纸”四项并不能证明第五项“柔性”。

一些 B2B/平台标题写 flexible、bendable 或 plastic，并不能单凭标题证明：TFT substrate（玻璃/塑料）、最小静态弯曲半径、禁止动态反复弯折、偏光/保护膜/封装层允许应力、FPC 位置和维修寿命。

### 3.2 供应商必须书面回答的内容

- 原厂、完整料号、修订版本、量产状态/生命周期；
- 真正塑料 TFT 基板的证据及彩色显示机制；
- 机械外形、有效显示区、FPC 位置、厚度、质量；
- **安装状态的最小弯曲半径**、弯曲方向和允许次数；不能默认“柔性=可频繁折叠”；
- 色数/分辨率、刷新模式、温度范围、色彩转换方式；
- 驱动 IC、电源轨、BUSY/RESET、SPI/8080/MIPI 等物理接口；
- 波形 LUT/驱动固件是否交付、NDA、二次开发/量产许可；
- P0 样品价、100/1000/5000 片报价、MOQ、有效期、交期、良率、DOA/售后；
- PCN/EOL、备选型号及至少一次返修渠道。

**P0 No-Go：** 无完整料号、真实柔性证据或合法可用的驱动资料时，不进入双屏采购或最终 PCB。标准玻璃 EPD 可以继续作为软件技术代理，但项目状态只能是“柔性屏待满足”。

### 3.3 显示路径取舍

| 路线 | 强项 | 限制 | 定位 |
|---|---|---|---|
| 柔性彩色 E-Ink | 反射式、低持续功耗、理念最吻合 | 料源/驱动/曲率/价格风险最高，刷新慢 | **原目标；Gate 驱动** |
| 玻璃彩色 E-Ink | 供货和开发板更容易，彩色数据链可先做 | 不满足柔性；抗冲击/安装限制 | **P0 技术代理，不代表最终交付** |
| OLED/LCD | 实时追焦、流畅循环动画更现实 | 持续供电、散热、亮度与外表面观感要重新设计 | **并行技术备选和后续版本** |

## 4. RW612 与软件控制平面

RW612 适合承担 BLE、Wi-Fi、命令路由、UWB 接口、状态/资产管理和显示提交调度。FRDM-RW612 官方资料展示 260 MHz Cortex-M33、1.2 MB SRAM，并在开发板上集成 QSPI Flash、pSRAM、MCU-Link。[R3]

推荐 Control Plane 与 Display Plane 物理/逻辑分离：

- E-Ink：RW612 + 双 EPD 驱动/电源域 + 本地预编译素材；
- OLED/LCD：RW612 保留控制、追踪和状态接口，高分辨率渲染/帧缓冲/视频解码另选显示处理器；
- App：手机 2D/3D 预览优先在手机本地执行。

禁止预设 RW612 单独实现双高清屏 60 fps 视频解码。不能因为开发板带 PSRAM 就忽略实际带宽、存取延迟和屏幕专用接口要求。

## 5. UWB/SR250 与 Camera Beacon

NXP 将 SR250 定位为支持 3D/360° AoA 的 UWB 方案，并有相关开发板/集成资料。[R4] **这代表芯片/方案能力，不等于佩戴后各方向均可获得同等精度或无死角。**

应验证：

1. SR250 与拟选 Beacon 的通信和角度输出是否真正互操作；
2. 方位角、俯仰角符号与安装朝向是否一致；
3. 前、侧、后方向的天线覆盖与盲区；
4. 用户头部/电池/假发/屏幕金属件遮挡；
5. 近距离、室内反射、多径/NLOS；
6. 运动时的更新率/有效样本比例；
7. Beacon 与真实镜头光轴的机械偏差及校准复现性；
8. 不同国家/地区的 UWB Channel/功率/占空比/认证要求。

Camera Beacon 的 SR040 / Murata Type 2DK 和 DWM3001C 可做候选/对照，但 **不能先写“SR040+SR250 组合已通过精度验证”**。[R5]

优先官方开发板或成熟多天线模块；P9–P12 在真实头壳中通过后再考虑自研裸 SR250 射频板和三天线阵列。

## 6. App / Commit / 素材系统可行性

已批准的四状态模型应保持：TrackingState、PreviewState、CommittedState、DisplayedState。

- E-Ink：预览/追踪建议不会直接修改物理眼片；每次外部动作须有显式 Send/Commit。
- Commit 必须含 Transaction ID、双眼作用域、不可变状态快照、素材版本/Hash、幂等键、接受/开始/左/右结果/完成或失败状态。
- 前一事务执行中，手机可以继续编辑下一版 Preview；未点击 Send 不会修改物理屏幕。
- 同一 Commit 断线重连后可查询结果；掉线后的未授权新事务不得自动执行。
- E-Ink 用户显式发送的“序列播放”允许该**同一事务内**按声明的有限步骤自主刷新；必须设结束条件、最大次数/总时长，防止无限刷新损耗与电耗。
- 头壳素材采用 Manifest、Asset ID、Version、Hash；平时 BLE 小命令，Wi-Fi 仅素材同步/OTA，默认拍摄关闭 Wi-Fi。
- microSD 不应承载唯一恢复映像；基本安全资源/故障恢复信息可放入 QSPI Flash。

V1 首发实现 STATIC + SEQUENCE；LAYERED / FRAME_ANIMATION / VIDEO 只预留协议兼容。

## 7. Head Fit / 2D / 3D 准确性

Head Fit 不是“瞳距”专用算法，而是每个头壳独立的左右眼变换：整体、左、右的 X/Y、缩放、旋转及眼眶 Mask。用户确认“设为原点”后，底层保存绝对安装变换，而运行层的微调相对该逻辑原点发生。

需要区分：

- Factory / Installation Calibration：物理安装和头壳固有偏差；
- Runtime Offset：表情、拍摄与手动调整；
- Tracking Offset：UWB 校零和摄影机偏移。

2D 预览可完全实现；3D 预览受模型表面/UV、遮挡形状、反射和物理外壳校准质量影响，不能承诺无标定即“所见即所得”。自定义 GLB/glTF 在后续 P14 实施。

## 8. macOS 工具链

NXP 官方提供 macOS x64 / Arm64 的 MCUXpresso Installer，并提供 RW612 和 SR250 的官方 Getting Started。[R6]

Mac 可作为日常开发、编译、烧录、调试、iOS/Android App、Python 素材处理的主机。但个别 EPD/国产模块供应商专用 LUT/配置/烧录工具可能仅有 Windows EXE，必须在 P0 逐项审查。不要把“主控可用 Mac 烧录”扩大为“所有第三方驱动工具绝不会依赖 Windows”。

### 11.1 敏感性

双屏在 100 台估计中约占 $180–300；屏幕单片变化 $20，会令整机单台成本变化 $40（未计损耗和税运）。优先谈判屏幕价格、良率和返修条款，而不是过度优化几美元的 MCU 或 IMU。

### 11.2 5/20/100 台的小批量

原研究只形成 100/1000 台的定量分项 BOM。**没有证据支持直接线性外推 5/20 台单价。** 5/20 台应拆分：样片单价、开发板/模块溢价、一次性工装、单台手工装配、良率、税运；取得供应商 RFQ 后再填实。新项目的成本模型会把 5/20 台标注为“缺报价，暂停承诺”，不伪造采购价。

## 12. 人力、工期与 NRE

原研究估算：

- 低/典型/高：**15.5 / 27.7 / 45.0 人月**；
- 3–5 人核心跨学科团队典型：**11–15 个日历月**；
- 1–2 人串行开发典型：**18–26 个月**。

人月是累计研发投入，不等于日历月；假设以成熟工具和部分并行开发为前提。中国企业全负担人月预算估计 ¥35,000–60,000，则典型 27.7 人月对应约 ¥0.97–1.66 百万元的工程规划资金；**个人自研的现金支出和机会成本应分开计算**。[R8]

## 13. 法规、射频与市场准入

- 中国 UWB 相关《超宽带（UWB）设备无线电管理暂行规定》2025-08-01 起实施；研究引用频率范围 **7163–8812 MHz**。具体产品和射频参数需按规定核实，并考虑型号核准要求。[R9]
- 美国需要按具体设备类别和用途核查 FCC 规则与认证途径；欧盟需满足 RED 2014/53/EU 的适用要求。[R10]
- CCC 不能仅凭“无线设备”标签判定是否适用；需按最终整机品类查目录。
- 任何开发板/认证模组使用也不能自动证明改装后整机获得认证或满足人体佩戴要求。
- 设计需支持 Region Profile（国家/地区可用频段与功率策略），但不得允许用户绕开本地法规自由切换到非法频段。

研究的合规预算**规划假设**：北美约 $8k–20k，欧洲约 €8k–20k，中国相关 SRRC/测试约 ¥50k–150k；这些是潜在实验室整改测试预算，不是官方收费表，也未包含所有市场准入费用。

## 14. 主要工程与商业风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 无真正柔性全彩约 7″ 的长期供货 | 首代产品路线失败 | P0 RFQ / 样品证据；玻璃屏仅代理；并行 OLED/LCD |
| EPD 10–20 s 级刷新与观感冲突 | 不适合连续眼神/视频 | E-Ink 只承诺静态/离散；Manual Commit |
| 波形 LUT/驱动授权不完整 | 无法量产和持续维护 | 合同确认开发、量产、升级使用权 |

| SR040/SR250 互操作未证 | 无法建立有效 AoA | 测试固件、UCI/FiRa 配置、备选 Beacon |
| 柔性屏反复装拆导致 FPC 疲劳 | 售后/破损成本 | 应力释放、固定半径、快拆保护、寿命试验 |

## 15. Go/No-Go 阶段门槛

以下数值是**工程建议验收目标**，不是原厂保证；实际基于产品需求再批准。

| Gate | 所属阶段 | 必须有的证据 | No-Go / 改道触发 |
|---|---|---|---|
| G0 | P0 柔性屏 | ≥3 供应商 RFQ；完整料号和 datasheet；授权可用驱动；样片 20–50 次刷新；弯曲/FPC/温度测试 | 无合格屏证据，不制作最终柔性 E-Ink PCB |
| G1 | P1–P3 双眼 | 每眼 ≥100 次切换；独立 BUSY/RESET；一眼错误不锁死另一眼 | 失效传播且不可隔离 |
| G2 | P4–P6 App | **未按 Send 实体绝不变化**；Head Profile 可复现；断线恢复 | 意外提交或无法恢复真实显示状态 |
| G3 | P7–P8 素材 | 断 Wi-Fi 时仍由本地素材播放；Manifest/Hash 一致 | 升级/断电造成资产库破坏 |
| G4 | P9–P12 UWB | 在实际头壳记录稳定方向输出 ≥30 min；多角度/遮挡测试；明确丢失策略 | AoA 大量不可用且校准/滤波不能改善 |
| G5 | P13–P15 扩展 | 2D/3D/实体共用 EyeState；OLED 实时接口无需重写控制协议 | 软件核心被 E-Ink 硬编码 |
| G6 | P16–P17 EVT/DVT | 20–50 工程样机；EMI 预扫；实际功率/热/机械/维修测试 | 关键料仅单一不可采购来源且 >26 周 |
| G7 | P18 PVT | 100 台测试计划；建议 FPY≥95%、单台校准≤8 min | FPY<90% 或屏/FPC 返修率不可接受 |

**停损纪律**：在 G0 未通过前，仅允许风险验证、小型技术代理样机与供应链调查；不锁定 Final PCB、线束连接器、量产电源，也不采购多套最终眼片。

## 16. 现有 V1.0 方案必须改动的内容

1. “首选”不等于“已证实”：RW612 与 SR250保留优先路线，SR040 保留候选，最终设备与兼容性均需联调证据。
2. 在 README 和硬件文档首页明确：**最终柔性 EPD 尚未确认**；Spectra 6 玻璃版本仅作代理。
3. 原 P0–P18 作为工作分解结构保留，但 P9 UWB 高风险验证提前并行启动；不给“只有到 P9 才开始 UWB”的风险积累。
4. 将 V1 兑现范围由“大而全功能清单”改为：STATIC、SEQUENCE、2D Preview、Manual Commit、Head Fit、UWB Preview。连续动画、视频、3D 和实时输出列为后续兼容/版本目标。
5. Commit 增加持久化、幂等和事务中左右眼部分成功的恢复；E-Ink 重复循环须限次数与时长。
6. 原价目仅为“初步候选”；更新成本模型标明报价证据、币种、汇率、量产级距、Beacon 独立计价、税运和 NRE。
7. macOS 作为主平台，但 Vendor Windows-only 工具不得隐瞒。
8. 供电仍然 **不设具体功率和电压**；测量结果出来后再形成 Power Budget。
9. 中国 RF 频率/型核和目标市场销售法规成为单独 Gate。
10. 允许失败时改道 LCD/OLED，但不能悄悄把用户的“柔性反射式首代”要求当作已满足。

## 17. 执行优先级（现在就做）

**优先级 0：供应商书面询价**。向至少三家真正的柔性彩色 EPD 供应商发 RFQ；缺料号/波形许可/弯曲数据/报价的供应商不能进入 G0。

**优先级 1：双平台并行风险消除**。屏幕代理台架（RW612 + 玻璃彩色 EPD，验证素材/Commit）与 UWB 台架（SR250+Beacon+实际头壳，验证角度/遮挡）可并行，不以复杂 App 完成为前置。

**优先级 2：先做一台可用的低风险 MVP**。完成 2D Preview、Manual Commit、Head Fit、本地 STATIC/SEQUENCE 及双眼独立后，再做 3D 和未来 OLED/LCD Display Plane。

**优先级 3：只有 G0/G1/G4/G6 证据充分时才投入最终 PCB、认证和小批量工装。**
