# P0：约 7 英寸真正柔性彩色电子纸选型与验证计划

> 版本：2026-11-06 / Draft for Execution  
> 目标：验证**满足真实柔性条件**的两眼屏，而不是只演示玻璃彩色 EPD。  
> 前置决策：[ADR-0001](../decisions/ADR-0001-risk-gated-v1.md)

## 1. P0 输出

必须产生五种证据：①可追溯料号与真实制造商；②显示、结构、接口、驱动/波形许可；③中国大陆采购和持续供货的有效书面报价；④带视频/日志的样片刷新测试；⑤用于后续机电设计的风险评审。

任何一项缺失，项目状态记为 **P0-Blocked**，不把代理样品误报成 G0 PASS。

## 2. 供应商 RFQ（至少 3 家，中文模板）

**主题：约 7 英寸柔性彩色电子纸屏与驱动开发资料询价**

我们拟用于 Kigurumi 头壳内左右双屏的静态彩色眼片项目，希望获得：

1. 原厂完整屏型号 / revision、有效区、分辨率、颜色/色域、屏幕厚度及重量；
2. 背板到底是塑料/柔性 TFT 还是玻璃（提供 datasheet 证明）；整屏封装层是否允许永久微弯；
3. 允许的最小静态弯曲半径、方向、最大反复弯曲次数、固定方法、FPC 安装及应力释放建议；
4. 对应驱动板、驱动 IC、接口和电压/电流时序、波形 LUT、初始化/刷新/断电演示；
5. MCU/自研硬件二次开发与量产的驱动、LUT、固件使用权和技术支持方式；
6. 0/5/20/100/1000/5000 片的价格（请写含税/未税、币种、运费、交期、MOQ、样片限制）；
7. 报价有效期、产品生命周期、PCN/EOL、退换 DOA、良率/返修条款；
8. 工作与仓储温度、彩色刷新时长、峰值电流、上电/断电/长期静态显示限制；
9. 是否能大陆开票采购、是否需签 NDA、有无停产替代。

请提供 datasheet、机械图、驱动说明、样品购买链接及可开发人员联系方式。

## 3. 样片采购策略

- 初次只采购 **1 块最终候选 + 对应原厂驱动板**；如厂家要求最少 2 块，记录原因。
- 玻璃 Spectra 6 / Good Display 代理板仅用于色彩变换、文件格式、BUSY 和 Commit 软件验证，必须在物料标签上标明 **PROXY — NOT FLEXIBLE**。
- 真正柔性屏 G0 通过且 FPC/机械定位确认后，再购第二块验证双眼；禁止先一次买大量屏。
- 所有采购记录附商品链接、发票、料号照片和收到日。

## 4. P0 台架

- 开发机：macOS Apple Silicon；优先 CLI 构建/烧录，可用厂商 Windows 工具时记录限制。
- 基础链路：PC/开发板 → EPD 原厂驱动 → 单屏。
- 工具：可靠稳压电源、功率/电流记录、温度计、逻辑分析仪（必要时）、柔性半径样规/治具、防静电台面、固定手机摄影记录。
- 最小测试素材：纯黑/白、主要色彩、棋盘格、边界细线、左右眼标定样张、不同 Gaze 的 5×5 小集。
- 电源域和屏驱动必须以**实际 datasheet**为准，不复制代理屏电压轨；原型不应擅自更改 EPD 高压驱动波形。

## 6. G0 Go / Conditional Go / No-Go

- **PASS**：上述 D-01/D-02/D-03/D-04/D-05/D-06/D-08/D-09/D-12 完备，通过，且计划采购规模与成本可接受。
- **CONDITIONAL**：软件代理验证成功，但柔性样屏尚未确认；可推进 BLE、Commit、App 和 UWB 台架，不能自称实装柔性 MVP。
- **NO-GO / PIVOT**：供应商长期不给驱动许可或真实柔性证据，可靠性/供货不足，或样屏成本明显不能支持目标用途；暂停该屏路线并评审玻璃 EPD 或 OLED/LCD 方案。改道需要用户明确批准，不能静默改变首代产品约束。
