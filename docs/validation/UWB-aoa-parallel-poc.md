# 并行 UWB PoC：SR250 真实头壳测向与 Camera Beacon 互操作

> 状态：设计/采购前验证；不代表 SR250/SR040 已实测成功  
> 优先级：与 P0 选屏并行，以便提前暴露高风险  
> 关联：[ADR-0001](../decisions/ADR-0001-risk-gated-v1.md)

## 1. 验证目标

在不使用任何摄像头、红外或光学传感器的条件下，测试头端 SR250 3D AoA（方位角 + 俯仰角 + 距离 + 质量）和摄影机 Beacon 在真实 Kigurumi 头壳中的可用性；区分原厂“3D/360° AoA 方案能力”和实际安装的视场、精度及盲区。

## 2. 采购与集成次序

1. 官方 SR250 开发板/成熟多天线模块 + 支持的 Host（优先 FRDM-RW612）。
2. SR040 / Murata Type 2DK 等可获取的 Tag 开发板；先确认其固件协议、频段、UCI/FiRa 配置是否与 SR250 实际互通。
3. 若联调不通，再评估 DWM3001C 或其它可验证互操作的 Beacon；不可单凭 UWB 兼容标志认定一定能做 3D AoA。
4. 在桌面验证方向输出后，加入实际头壳/假发/供电/显示子板，以固定治具反复测量。
5. 地区法规：先核查中国现行 UWB 发射频率与型号核准要求，选用合法允许的实验频段/条件；不要因开发示例默认频道而越过法定范围。

## 3. 测试记录字段

- 时间戳、设备/固件版本、Beacon_ID、Region Profile；
- 相对真实方向与估计 azimuth/elevation/range；
- 有效性和质量标记、包丢失率、数据更新率；
- 环境（空旷/室内多径/人员走动）、头壳佩戴状态、RF 天线安装朝向；
- 前方、左/右 ±30°、±60°、上/下 ±20°、背面/侧后盲区；
- 距离至少在典型摄影位（例如约 1/2/3/5 m）测试，实际范围可按场地修改；
- 受金属/电池/屏幕 FPC 和人体遮挡影响的失败时间段；
- 连续 ≥30 分钟运行稳定性，重连、突然遮挡、目标丢失和恢复。

## 4. 拟议通过门槛（先评审，再作为正式指标）

- 能够稳定给出方向与质量标志，且错误估计能通过质量/稳定阈值识别；
- 典型摄影位持续 30min 没有程序/链路死锁；
- 前方常用拍摄角的有效方向数据占比建议 ≥95%，但 **该数字是产品验收提案，非 NXP 保证**；
- 方位/俯仰 p95 误差先记录实测分布；正式阈值须根据 5×5 E-Ink gaze cell 角区间和实际成像验证确定；
- 射频天线必须有可在头壳内安置的体积、固定结构与 RF 净空；
- 如果侧后角存在大盲区，可以限定真实追焦可用角域，不能宣称 360° 实装无盲区。

## 5. 丢失与输出语义

- E-Ink MANUAL_COMMIT：TrackingState 只在手机预览，未点击 Send 不会变实体。
- OLED/LCD REALTIME：短暂丢失保持最后有效 Gaze，并向手机告警；超时行为须可配置且受安全约束。
- V1 选择一个明确 Beacon_ID；不自动追踪最近 Beacon。
- Beacon 到镜头的水平/垂直偏移单独校准，未来可提升 XYZ。

## 6. 决策

- **Pass**：能够稳定复现相机方向，丢失边界可识别，有合理的 RF 安装空间与合规计划。
- **Conditional**：前方拍摄可用，但侧后存在盲区；App 标注支持的追焦空间，仍可保留 UWB 预览。
- **Fail / Pivot**：在合理位置与标定下仍持续漂移/无有效方向，或协议不可互通；回到供应商/模块路线重新选择，不在正式头壳 PCB 上继续堆补丁。
